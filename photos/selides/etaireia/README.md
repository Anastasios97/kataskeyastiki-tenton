# 📷 Η εταιρεία

**Πού εμφανίζονται:** Φωτογραφία στην ενότητα «Η εταιρεία» (αρχική και σελίδα «Η εταιρεία μας»). Με 2+ φωτογραφίες εμφανίζεται και γκαλερί στη σελίδα της εταιρείας.

- Ανεβάστε εδώ όσες φωτογραφίες θέλετε (JPG, PNG ή WebP). Όσες ανεβάσετε, τόσες θα φαίνονται.
- **Κεντρική φωτογραφία:** αυτή που έχει στο όνομα τη λέξη `kentriki` (π.χ. `01-kentriki.jpg`). Αν δεν υπάρχει, κεντρική γίνεται η πρώτη αλφαβητικά.
- **Σειρά:** αλφαβητική/αριθμητική με βάση το όνομα αρχείου (`01.jpg`, `02.jpg`, … `10.jpg`).
- Δεν χρειάζεται να μικρύνετε τις φωτογραφίες· η ιστοσελίδα τις συμπιέζει και τις γυρίζει σωστά αυτόματα.
